# Project Euler Solutions in C++

![Problems: 984](https://img.shields.io/badge/Problems-984-brightgreen)

This repository collects C++ solutions for Project Euler, from early classics to recent high-number challenges. Source files follow a simple naming rule, `Euler{N}.cpp`, so each problem is easy to locate. Implementations prioritize clear mathematics, fast runtime, and lean code.

## Euler in 4 Moments
- **1707**: Leonhard Euler is born in Basel, Switzerland.
- **1727**: He joins the St. Petersburg Academy and begins his major research career.
- **1741**: He starts his Berlin Academy period, producing landmark work in analysis and number theory.
- **1766**: He returns to St. Petersburg and continues publishing at an extraordinary pace.

## Quick Start
```bash
g++ -O2 -std=c++17 Euler1.cpp -o euler1
./euler1
```

This archive keeps growing across both foundational and modern Project Euler problems.
